초안이라 사이트에는 나오지 않는다. 글을 쓸 때 필요한 부분을 복사해 쓰고, 필요 없으면 지워도 된다.

## 제목과 문단

`##` 가 큰 제목, `###` 가 작은 제목이다. 글 제목은 머리말의 제목 칸에 적으므로 본문에서 `#` 하나짜리 제목은 쓰지 않는다.

문단은 빈 줄로 나눈다. **굵게**, *기울여서*, `코드처럼` 쓸 수 있다. 링크는 [Astro 문서](https://docs.astro.build)처럼 쓴다.

- 목록은 줄 앞에 `-` 를 붙인다.
- 번호 목록은 `1.` 을 붙인다.

> 인용은 줄 앞에 `>` 를 붙인다.

## 수식

문장 안에서는 달러 기호 하나로 감싼다. 예: $W = W_0 + BA$, $\alpha_{i} \cdot x_{j}$.

금액처럼 달러 기호를 글자로 쓸 때는 `\$5` 처럼 앞에 역슬래시를 붙인다. 붙이지 않으면 한 문단 안의 달러 기호 두 개 사이가 수식으로 바뀐다.

따로 한 줄에 쓸 때는 달러 기호 두 개로 감싼다.

$$
\begin{aligned}
h &= W_0 x + BAx \\
\mathcal{L} &= -\sum_{i=1}^{N} \log p(y_i \mid x_i)
\end{aligned}
$$

## 코드

백틱 세 개 뒤에 언어 이름을 적는다.

```python
def rank(scores: list[float], k: int = 5) -> list[int]:
    return sorted(range(len(scores)), key=lambda i: -scores[i])[:k]
```

## 그림

관리 화면의 그림 모양 단추(에셋)를 눌러 「글」 폴더에 그림을 올린 다음, 거기 보이는 파일 이름을 그대로 적는다.

```markdown
![그림 설명](./images/파일이름.png)
```

파일 이름이 틀리면 사이트가 갱신되지 않으므로, 미리 보기에 그림이 보이는지 확인하고 저장한다.
